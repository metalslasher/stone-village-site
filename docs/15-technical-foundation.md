# Технічна основа Stone Village

## Вибір стеку

Astro 7 + TypeScript 6 + звичайний CSS. Попереднього стеку в репозиторії не було. Сторінки генеруються в HTML; клієнтський JavaScript додається тільки для потрібних взаємодій. Не встановлені React, Tailwind, UI libraries, animation libraries, CMS або серверний adapter.

TypeScript 6 обраний відповідно до peer dependencies @astrojs/check; TypeScript 7 наразі не входить у заявлений діапазон сумісності цього checker. Версії зафіксовані, інсталяція відтворюється через npm ci.

Статична основа підходить для головної, двох сторінок будинків і сторінки подяки. Майбутнє приймання заявок потребуватиме окремого серверного endpoint або adapter залежно від хостингу. Статична форма сама по собі не забезпечує серверну валідацію чи доставку в CRM.

## Що створено

- src/layouts/SiteDocument.astro: українська мова, viewport, title/description, noindex для поточного етапу, skip-link.
- src/styles/: tokens, мінімальний reset, типографіка, вирівнювання і доступність.
- src/content/: окремі записи дуплексу й котеджу, загальний зміст та типізація походження медіа.
- src/config/integrations.ts: явно не налаштовані інтеграції без вигаданих ID чи контактів.
- src/components/foundation/: локальний стенд перевірки основи.
- src/assets/: майбутні відібрані зображення для обробки Astro.
- public/: майбутні статичні логотипи, шрифти й відео.
- assets/research/: збережена дослідницька колекція, яка не копіюється в публічну збірку.

Директорії майбутніх секцій створюватимуться разом з реалізацією; порожніх Card/Button/Section або фіктивних компонентів немає. Структура відповідальностей описана у src/components/README.md.

## Responsive foundation

Плавні gutters і font sizes через clamp. Сітка: 4 колонки, від 48rem — 8, від 75rem — 12. Це базові орієнтири, не жорсткі межі для всіх історій. Кожна секція визначає власні композиційні зміни. Немає глобального section padding, фіксованої висоти секцій чи примусового обрізання горизонтального overflow.

Цільові viewport для перевірки: 320, 390, 768, 1024, 1440, 1920 px. Зображення будуть отримувати власні desktop/mobile focal points. Мінімальна висота інтерактивних елементів — 44px.

## Typography і tokens

Системний sans-serif з українськими символами використовується як тимчасова основа без мережевого завантаження шрифтів. Остаточна брендова гарнітура ще не обрана; після вибору ліцензовані WOFF2 зберігатимуться локально. Окремі ролі display, heading, lead, body, caption; контент не прив'язаний до випадкового розміру HTML-тега.

Палітра: paper, surface, ink, muted, stone, line, accent, focus, error. Є шкала spacing, максимальна ширина, міжколонковий відступ, line-height, довжина текстового рядка і стримані motion durations. Палітра є робочою реалізацією docs/07-design.md, не новим затвердженим брендингом.

## Межі поточного етапу

Погоджений посекційний план з розмови прийнятий. Спочатку технічна основа, потім відбір assets, hero та окремі продуктові композиції, далі інші секції. Весь сайт зараз не будуємо.

Кореневий маршрут тимчасово показує технічний стенд. Перед публікацією замінити його головною і видалити FoundationPreview. Domain/canonical, OG image, sitemap/robots та інтеграції налаштувати після визначення реального домену й контенту. Нічого не розгорнуто публічно.

## Перевірки

npm run build спочатку виконує astro check, а потім генерує статичний HTML. Browser QA поточного етапу стосується лише технічного стенда. Повний цикл desktop/mobile для кожної великої секції залишається обов'язковим під час її реалізації.

Перевірено 2026-09-06: build/check — 0 errors, 0 warnings; Chromium на 320/390/768/1024/1440/1920 px — без горизонтального переповнення. Desktop 1440 і mobile 390 переглянуті візуально, після усунення накладання dev-toolbar зроблено повторні скриншоти. Tab переводить фокус на skip-link з видимим outline. HTML має lang=uk і noindex. Production output не містить клієнтського JS застосунку. Safari, Firefox і реальні мобільні пристрої на цьому етапі не перевірялися.
