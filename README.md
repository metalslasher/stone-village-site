# Stone Village

Промосайт на Astro 7, TypeScript 6 і native CSS. Поточний фокус — наповнення, дизайн та адаптивність.

## Звідки брати контекст
1. [AGENTS.md](AGENTS.md) — правила роботи й пріоритети.
2. [Чинний стан і рішення](docs/00-current-state.md) — єдиний актуальний опис.
3. docs/01–12 — тематичні матеріали, вибирати за задачею.
4. docs/13-presentation.pdf — інформаційна презентація, не шаблон верстки.
5. docs/14–25 — історичні звіти, джерела й перевірки; не поточний план.

## Локальний сайт
Реалізовані головна, /duplex-185/ і /cottage-228/. Планування доступні на сторінках будинків. CTA відкриває лід-форму без надсилання. Сайт має noindex; інтеграції та публічний запуск відкладені.

Потрібні Node.js 22.12+ і npm. Версії залежностей зафіксовані в package-lock.json.

```sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

## Склад репозиторію

Робочі медіа включені в src/assets і public; документація та презентація — у docs. Локальні дослідницькі колекції assets/, залежності й результати збірки не завантажуються в Git. Посилання на ці локальні артефакти в історичних звітах є довідковими. Для запуску достатньо клонування, npm ci та npm run dev.
